# PlanAI Site v2

Site de apresentação do PlanAI (planilhas inteligentes com dashboard, gráfico, copilot e colaboração), refeito do zero. HTML/CSS/JS estático, sem framework, PT/EN, tema claro/escuro, fontes locais e sem rastreamento.

- `index.html`: landing
- `privacidade.html`: aviso de privacidade (LGPD)
- `404.html`: página não encontrada
- `assets/`: CSS, JS, fontes e logos otimizados

Ver localmente: `npx serve .`

Demo: https://planai.onrender.com
